## Зачем это нужно

В работе с ассистентом многие ответы короткие и предсказуемые: «продолжай», «запусти тесты», «покажи изменения». Этот плагин пишет такую реплику заранее и оставляет её в поле ввода.

<table>
<tr>
<td width="33%" valign="top">

### ⌨️ Меньше печатать

Типовые реплики вставляются одной клавишей. После вставки это обычный текст, как набранный вручную: его можно править и отменять.

</td>
<td width="33%" valign="top">

### 🤫 Не мешает

Стоит начать печатать — подсказка сразу уступает место. Во время набора через IME и при открытом меню она не появляется. Если модель не уверена, она ничего не предлагает.

</td>
<td width="33%" valign="top">

### 🛡️ Не превышает полномочий

Плагин только помещает текст в поле ввода. В нём нет никакого кода «отправить сообщение»; отправлять или нет — всегда решаете вы.

</td>
</tr>
<tr>
<td valign="top">

### 💰 Расходы под контролем

По умолчанию используется недорогая модель, действуют дневные пределы запросов и токенов. Короткие фразы, которые вы повторяете, предлагаются напрямую, без вызова модели.

</td>
<td valign="top">

### 🔒 Конфиденциальность прежде всего

Перед отправкой скрываются предполагаемые ключи, токены, адреса электронной почты и номера телефонов. Браузер никогда не передаёт ваш черновик. Локальная статистика хранит числа, а не текст.

</td>
<td valign="top">

### 📊 Прозрачный расход

Число запросов, доля принятых подсказок, время ответа и расход токенов за последние 7 дней показаны на странице настроек — сразу видно, стоит ли оно того.

</td>
</tr>
</table>

## Возможности

### Подсказка прямо в поле ввода

Если после ответа ассистента поле ввода пусто, серая подсказка появляется именно там, где вы собирались печатать. Никаких всплывающих окон и занятого места.

<p align="center">
  <img src="docs/images/suggestion.png" width="720" alt="Серая подсказка в поле ввода, справа — «Tab — принять» и «Другая»">
</p>

| Клавиша | Что делает |
|---|---|
| <kbd>Tab</kbd> или <kbd>→</kbd> | Вставляет подсказку в поле ввода, где её можно править дальше; <kbd>Ctrl</kbd>+<kbd>Z</kbd> отменяет только эту вставку |
| <kbd>Esc</kbd> | Скрывает подсказку |
| <kbd>Alt</kbd>+<kbd>\\</kbd> (можно изменить) | Предсказывает немедленно; если подсказка уже показана — переключает на другую. Один вызов возвращает несколько вариантов, поэтому переключение мгновенное |
| Просто печатать | Подсказка сразу исчезает; она вернётся, когда вы очистите поле ввода |

### Три режима, один щелчок

Не хотите разбираться в каждом параметре? Выберите режим. Его можно отменить или подстроить позже.

<p align="center">
  <img src="docs/images/modes.png" width="720" alt="Карточка режимов: Сбалансированный, Экономный, Качество">
</p>

| Режим | Когда предсказывает | Модель | Контекст | Дневной предел | Для чего подходит |
|---|---|---|---|---|---|
| **Сбалансированный** (Рекомендуется) | Автоматически после каждого ответа | Конкретная недорогая модель | 12 сообщений | 200 запросов | Повседневная работа |
| **Экономный** | Только по кнопке «Предсказать» или сочетанию клавиш | Конкретная недорогая модель | 6 сообщений | 60 запросов | Строгий контроль расходов |
| **Качество** | Автоматически после каждого ответа | Модель сеанса | 20 сообщений | 200 запросов | Более точные подсказки |

Режим меняет только способ запуска, стратегию выбора модели, размер контекста и пределы. Он не трогает главный переключатель, сочетание клавиш, язык и параметры конфиденциальности и сохраняет указанную вами модель.

### Девять языков интерфейса

Страница настроек, кнопки в поле ввода и их всплывающие подсказки доступны на следующих языках: 简体中文, English, 日本語, 한국어, Español, Français, Deutsch, Русский, Português. По умолчанию плагин использует язык, выбранный в DeepSeek Harness; его также можно выбрать отдельно в разделе **Настройки → Предсказание → Язык**, и он применяется сразу. Язык самих подсказок всегда соответствует языку беседы.

## Установка

Требуется DeepSeek Harness `0.2.2-rc.1` (`>=0.2.2-rc.1 <0.3.0`). У плагина нет сторонних зависимостей, и собирать его не нужно. Устанавливается одной командой:

```powershell
dsh plugin --profile desktop add github:KungerChen/dsh-next-message-predictor
```

После `--profile` указывается профиль, которым вы пользуетесь: `desktop` для настольного приложения, `web` для веб-версии. Затем **полностью закройте DSH и запустите его снова**.

<details>
<summary>Команда <code>dsh</code> не найдена, или вы хотите установить из локальной папки</summary>

Утилита командной строки `dsh` находится в папке установки DeepSeek Harness, её можно вызвать по полному пути. Если вы хотите менять код сами, клонируйте репозиторий и установите плагин из локальной папки:

```powershell
git clone https://github.com/KungerChen/dsh-next-message-predictor.git
$dsh = '<папка установки DSH>\resources\runtime\cli\bin\dsh.cmd'
& $dsh plugin --profile desktop add '<папка плагина>'
```

`<папка установки DSH>` — место, куда установлен DeepSeek Harness; `<папка плагина>` — только что клонированная папка.

</details>

Дальше три шага:

1. Откройте **Настройки → Предсказание** и включите «Включить предсказание». По умолчанию выключено: пока вы не включите, подсказки не показываются и модель не вызывается.
2. Выберите один в разделе «Режим». По умолчанию — «Сбалансированный».
3. Чтобы открывать быстрее, нажмите «Добавить на боковую панель» в правом верхнем углу.

<details>
<summary>Обновление и удаление</summary>

**Обновление**: если плагин установлен с GitHub, удалите его и снова выполните команду установки; если из локальной папки — выполните в ней `git pull`. Затем перезапустите DSH. Обновить страницу недостаточно: страница станет новой, а фоновая часть останется старой, и страница настроек сообщит о несовпадении версий.

**Удаление**:

```powershell
dsh plugin --profile desktop remove dsh-next-message-predictor
```

В одном профиле включайте только один плагин предсказаний для поля ввода. Обнаружив другой такой плагин, этот приостанавливается сам и объясняет причину на странице настроек.

</details>

## Что отправляется

Каждое предсказание — один запрос к модели, без автоматических повторов. В него входят фрагменты последних **сообщений пользователя и итоговых текстовых ответов ассистента** из текущего сеанса: по умолчанию не более 12 сообщений и около 2 000 токенов.

- Аргументы и вывод инструментов, рассуждения и системный промпт не включаются.
- Перед отправкой предполагаемые закрытые ключи, ключи API, токены, пароли, адреса электронной почты, номера мобильных телефонов и удостоверений личности, а также имя пользователя в путях домашней папки заменяются заполнителями (механизм работает по правилам и не может гарантировать, что найдёт всё).
- Страница в браузере передаёт только идентификаторы сеанса и хода — ни черновик, ни вложения, ни текст беседы; содержимое для модели читает фоновая часть из собственных записей сеанса DSH.
- «Отдавать предпочтение часто используемым коротким сообщениям» лишь сравнивает короткие сообщения, отправленные вами на этом компьютере; модель не вызывается.

Полное описание и способ удалить локальные данные — в документе [Конфиденциальность и границы данных](docs/PRIVACY.md).

## Частые вопросы

<details>
<summary><b>Отправит ли он сообщение за меня?</b></summary>

Нет. Принятие подсказки только помещает текст в поле ввода через его собственный интерфейс вставки; в коде плагина нет вызовов, которые что-либо отправляют или подтверждают.

</details>

<details>
<summary><b>Сколько это стоит?</b></summary>

Каждое предсказание — очень короткий вызов модели (по умолчанию не более 96 выходных токенов). Дневные пределы по умолчанию — 200 запросов и 500 000 токенов; после их достижения вызовов в этот день больше нет. Чтобы тратить меньше, выберите режим «Экономный»: он предсказывает только по вашей просьбе. Фактический расход показан в разделе «Последние 7 дней» на странице настроек.

</details>

<details>
<summary><b>Почему иногда подсказки нет?</b></summary>

Так задумано: если модель не уверена, она ничего не предлагает, а вывод, нарушающий правила (слишком длинный, многострочный, написанный от лица ассистента), отбрасывается. Строка состояния на странице настроек объясняет, почему подсказки нет прямо сейчас. Когда она нужна, нажмите <kbd>Alt</kbd>+<kbd>\\</kbd>.

</details>

<details>
<summary><b>Насколько точны подсказки?</b></summary>

Плагин хорошо справляется с короткими и ясными репликами: подтвердить, попросить проверить, уточнить детали. Угадать то, что знаете только вы, он не может — и в этом случае должен молчать.

</details>

## Участие в разработке

```powershell
npm run build   # создаёт lib/client.js из src/shared + src/client
npm test        # модульные и интеграционные тесты, всего 242
npm run check   # сборка + тесты + проверка синтаксиса
```

`npm install` не нужен, сборщика нет; требуется Node.js 22 или новее. Чтобы добавить или исправить перевод, отредактируйте `src/client/locales/<язык>.js`; тесты проверяют, что у всех языков одинаковый набор ключей.

## Известные ограничения

- Проверено только на DSH `0.2.2-rc.1`.
- При сохранении настройки хост перезапускает фоновую часть плагина; выполняющееся предсказание отменяется.
- Несколько окон используют общие результаты предсказаний; скрытие подсказки в одном окне не передаётся в другие в реальном времени.
- Палитра команд и диалог обратной связи распознаются по фокусу и признакам модальности; ошибка распознавания означает лишь одну непоказанную подсказку, но не перехваченное нажатие клавиши.
