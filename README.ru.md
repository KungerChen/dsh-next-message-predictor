<a name="quick-start"></a>

## Быстрый старт

Для установки подходит DeepSeek Harness `>=0.2.2-rc.1 <0.3.0`. Пакет с GitHub уже готов к установке.

```powershell
dsh plugin --profile desktop add github:KungerChen/dsh-next-message-predictor
```

Укажите свой профиль DSH (по умолчанию `desktop` для приложения и `web` для веб-версии). Затем **полностью закройте и снова откройте DSH**.

1. Откройте **Настройки → Предсказание**. При первой установке прогнозирование выключено.
2. Выберите режим в разделе «Режим». В разделе «Модель для предсказаний» проверьте провайдера и модель, настроенные в DSH, либо выберите «Как в сеансе». Сохраните изменения полей модели.
3. Включите «Включить предсказание» и оставьте поле пустым после ответа. Для ручной проверки нажмите «Предсказать» либо переведите фокус в пустое поле и нажмите <kbd>Alt</kbd>+<kbd>\</kbd>.

В режимах баланса и экономии по умолчанию задана модель `deepseek-official / deepseek-flash`. Для другой модели укажите её ID и ID провайдера в DSH. Если DSH не сможет найти указанную модель, для этого прогноза может использоваться доступная модель DSH по умолчанию.

<details>
<summary>Команда <code>dsh</code> не найдена, или вы хотите установить из локальной папки</summary>

Утилита командной строки `dsh` находится в папке установки DeepSeek Harness, её можно вызвать по полному пути. Если вы хотите менять код сами, клонируйте репозиторий и установите плагин из локальной папки:

```powershell
git clone https://github.com/KungerChen/dsh-next-message-predictor.git
$dsh = '<папка установки DSH>\resources\runtime\cli\bin\dsh.cmd'
& $dsh plugin --profile desktop add '<папка плагина>'
```

</details>

<details>
<summary>Обновление и удаление</summary>

**Обновление**: если плагин установлен с GitHub, удалите его и снова выполните команду установки; если из локальной папки — выполните в ней `git pull`. Затем перезапустите DSH. Обновить страницу недостаточно: страница станет новой, а фоновая часть останется старой, и страница настроек сообщит о несовпадении версий.

**Удаление**:

```powershell
dsh plugin --profile desktop remove dsh-next-message-predictor
```

В одном профиле включайте только один плагин предсказаний для поля ввода. Обнаружив другой такой плагин, этот приостанавливается сам и объясняет причину на странице настроек.

</details>

## Предпросмотр и вставка

Доступная подсказка отображается серым в пустом поле активного окна. По умолчанию её видно и без фокуса. Настройка «Показывать прогнозы только при фокусе на поле ввода» ограничивает показ полем с фокусом. Этот параметр управляет показом уже полученных подсказок.

<p align="center">
  <img src="docs/images/suggestion.png" width="720" alt="Серая подсказка в поле без фокуса и указание перевести фокус перед нажатием Tab">
</p>

| Действие в поле ввода | Что делает |
|---|---|
| <kbd>Tab</kbd>, <kbd>→</kbd> в начале поля или кнопка «Tab — принять» | Сначала переведите фокус в поле ввода. Вставленный черновик можно отредактировать перед отправкой. |
| <kbd>Esc</kbd> | Скрывает подсказку, когда поле в фокусе. Затем можно вручную запросить новую. |
| <kbd>Alt</kbd>+<kbd>\</kbd> (можно изменить), «Предсказать» или «Другая» | Запрашивает прогноз или показывает другую подсказку, если поле пусто. Сочетание клавиш также требует фокуса в поле. |
| Просто печатать | Начало ввода скрывает подсказку. После очистки черновика она может вернуться, если ещё действительна. |

После вставки отмените её через <kbd>Ctrl</kbd>+<kbd>Z</kbd> или повторите через <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>. В 0.6.0 исправлена отмена первой вставки после отправки сообщения в проверенном редакторе DSH Desktop `0.2.2-rc.3`. В других версиях редактора действует штатная история DSH. [Отчёт о проверке](docs/VALIDATION-DISPLAY-SESSION.md)

<a name="session-pause"></a>

## Пауза в текущем разговоре

Кнопка паузы на панели поля ввода приостанавливает автоматические и ручные прогнозы в этом разговоре и убирает подсказку. Нажмите ▶, чтобы возобновить прогнозы, затем запросите новый вручную или дождитесь следующего ответа.

<p align="center">
  <img src="docs/images/pause.png" width="720" alt="Разговор с приостановленными прогнозами и кнопка возобновления на панели поля ввода">
</p>

Окна, подключённые к одному хосту DSH, разделяют состояние паузы. Оно сохраняется при обновлении страницы и сохранении настроек до возобновления или перезапуска DSH. Если вставить или скрыть подсказку, подсказки для этого ответа исчезнут и в других окнах того же разговора.

<a name="modes"></a>

## Режимы прогнозирования

<p align="center">
  <img src="docs/images/modes.png" width="720" alt="Карточка режимов: Сбалансированный, Экономный, Качество">
</p>

| Режим | Когда предсказывает | Модель | Сообщений контекста, макс. | Лимит запросов в день |
|---|---|---|---|---|
| **Сбалансированный** (Рекомендуется) | Автоматически после подходящего ответа | Указанная модель | 12 | 200 |
| **Экономный** | Только вручную | Указанная модель | 6 | 60 |
| **Качество** | Автоматически после подходящего ответа | Модель сеанса | 20 | 200 |

Режимы меняют запуск прогнозов, выбор модели, объём контекста и лимиты. Общий переключатель, сочетание клавиш, язык, настройки приватности и введённые ID модели сохраняются.

### Подсказки модели и свои фразы

После подсказок модели могут появиться короткие сообщения, которые вы повторяли в этом разговоре, и закреплённые фразы. Добавьте или переставьте фразы в **Настройки → Предсказание → Источники подсказок → Закреплённые фразы**, затем сохраните список. Кнопка «Другая» переключает доступные варианты без нового запроса к модели. Когда доступные варианты закончатся, запрос следующего может обратиться к модели с учётом лимитов.

Если ручной прогноз не дал подходящего результата модели, плагин может предложить ваши фразы. Для подготовки такой замены дополнительный запрос к модели не нужен.

## Конфиденциальность и запросы к модели

При прогнозе модель получает отрывки недавних **сообщений пользователя и окончательных ответов ассистента** из текущей ветви разговора. Получатель — провайдер, настроенный в DSH. По умолчанию входной лимит составляет 12 сообщений и около 2000 токенов с инструкциями.

- По умолчанию добавляется короткая сводка количества действий в предыдущем ходе. Аргументы и вывод инструментов, рассуждения и системные инструкции исключены.
- По умолчанию правила маскируют вероятные секреты и некоторые персональные идентификаторы. Часть чувствительного текста может остаться.
- Запросы прогнозов и состояния из браузера содержат идентификаторы и метаданные. Бэкенд читает отправленные сообщения из DSH. Черновики, вложения и ссылки на сообщения исключены. Локальная статистика хранит счётчики, время и идентификаторы без текста разговоров и подсказок.
- Локальные варианты и список закреплённых фраз не добавляются в запрос к модели. Уже отправленная вами фраза может попасть в недавний контекст разговора.

Полное описание и способ удалить локальные данные — в документе [Конфиденциальность и границы данных](docs/PRIVACY.md).

## Частые вопросы

<details>
<summary><b>Почему подсказка не появилась?</b></summary>

Посмотрите текущий статус в настройках. Паузу, неактивное окно, черновик, открытое меню или активный ввод через IME учитывают при показе. Модель также может не дать подходящего варианта. В подходящем разговоре можно запросить прогноз из пустого поля с фокусом.

</details>

<details>
<summary><b>Когда запросы оплачиваются?</b></summary>

Стоимость зависит от фактического провайдера и использованных токенов. Переключение доступных вариантов и подбор локальной замены не добавляют запросов к модели. Режим экономии позволяет прогнозировать только по запросу.

</details>
