inst_profile: Укажите свой профиль DSH (по умолчанию `desktop` для приложения и `web` для веб-версии). Затем **полностью закройте и снова откройте DSH**.
s1: Откройте **Настройки → {ui:settings.nav}**. При первой установке прогнозирование выключено.
s2: Выберите режим в разделе «{ui:preset.title}». В разделе «{ui:settings.routeTitle}» проверьте провайдера и модель, настроенные в DSH, либо выберите «{ui:settings.routeModeSession}». Сохраните изменения полей модели.
s3: Включите «{ui:settings.enabled}» и оставьте поле пустым после ответа. Для ручной проверки нажмите «{ui:ghost.predict}» либо переведите фокус в пустое поле и нажмите <kbd>Alt</kbd>+<kbd>\</kbd>.
route_note: В режимах баланса и экономии по умолчанию задана модель `{fact:default_provider} / {fact:default_model}`. Для другой модели укажите её ID и ID провайдера в DSH. Если DSH не сможет найти указанную модель, для этого прогноза может использоваться доступная модель DSH по умолчанию.

f1_p: Доступная подсказка отображается серым в пустом поле активного окна. По умолчанию её видно и без фокуса. Настройка «{ui:settings.requireInputFocus}» ограничивает показ полем с фокусом. Этот параметр управляет показом уже полученных подсказок.

k_th1: Действие в поле ввода
k_th2: Что делает
k1a: <kbd>Tab</kbd>, соответствующая кнопка или <kbd>→</kbd> в начале поля
k1b: Сначала переведите фокус в поле ввода. По умолчанию подсказка вставляется в черновик. Если включить «{ui:settings.sendOnTab}», клавиша Tab и соответствующая кнопка отправят текущую подсказку. Стрелка вправо всегда вставляет подсказку только в черновик. Отправка возможна, пока подсказка действительна и выполнены условия отправки. Перед включением учтите риск случайной отправки.
k2a: <kbd>Esc</kbd>
k2b: Скрывает подсказку, когда поле в фокусе. Затем можно вручную запросить новую.
k3a: <kbd>Alt</kbd>+<kbd>\</kbd> (можно изменить), «{ui:ghost.predict}» или «{ui:ghost.another}»
k3b: Запрашивает прогноз или показывает другую подсказку, если поле пусто. Сочетание клавиш также требует фокуса в поле.
k4a: Просто печатать
k4b: Начало ввода скрывает подсказку. После очистки черновика она может вернуться, если ещё действительна.
undo: После вставки отмените её через <kbd>Ctrl</kbd>+<kbd>Z</kbd> или повторите через <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd>. В 0.6.0 исправлена отмена первой вставки после отправки сообщения в проверенном редакторе DSH Desktop `0.2.2-rc.3`. В других версиях редактора действует штатная история DSH. [Отчёт о проверке](docs/VALIDATION-DISPLAY-SESSION.md)

send_p: При прогнозе модель получает отрывки недавних **сообщений пользователя и окончательных ответов ассистента** из текущей ветви разговора. Получатель — провайдер, настроенный в DSH. По умолчанию входной лимит составляет {fact:default_context_messages} сообщений и около {fact:default_input_tokens} токенов с инструкциями.
sb1: По умолчанию добавляется короткая сводка количества действий в предыдущем ходе. Аргументы и вывод инструментов, рассуждения и системные инструкции исключены.
sb2: По умолчанию правила маскируют вероятные секреты и некоторые персональные идентификаторы. Часть чувствительного текста может остаться.
sb3: Запросы прогнозов и состояния из браузера содержат идентификаторы и метаданные. Бэкенд читает отправленные сообщения из DSH. Черновики, вложения и ссылки на сообщения исключены. Локальная статистика хранит счётчики, время и идентификаторы без текста разговоров и подсказок.
sb4: Локальные варианты и список закреплённых фраз не добавляются в запрос к модели. Уже отправленная вами фраза может попасть в недавний контекст разговора.

faq_h: Частые вопросы
q1: Почему подсказка не появилась?
a1: Посмотрите текущий статус в настройках. Паузу, неактивное окно, черновик, открытое меню или активный ввод через IME учитывают при показе. Модель также может не дать подходящего варианта. В подходящем разговоре можно запросить прогноз из пустого поля с фокусом.
q2: Когда запросы оплачиваются?
a2: Стоимость зависит от фактического провайдера и использованных токенов. Переключение доступных вариантов и подбор локальной замены не добавляют запросов к модели. Режим экономии позволяет прогнозировать только по запросу.
