# 使用指南

适用版本：0.4.0。

## 1. 建议怎么出现、怎么用

助手回答结束后，如果输入框是空的，插件会请一个模型预测你接下来最可能发的一条消息，并以灰色文字显示在输入框里。

| 操作 | 效果 |
|---|---|
| `Tab` 或 `→` | 把建议填入输入框。填入后和你自己打的字一样，可以修改；`Ctrl+Z` 只撤销这次填入。**不会发送。** |
| `Esc` | 隐藏这条建议，这次回答不再自动给出。 |
| `Alt+\`（可改） | 输入框为空时立即预测；已有建议时切换到下一条。 |
| 点击“Tab 采纳” | 同 `Tab`。 |
| 点击“换一条” | 同快捷键。有多条候选时显示 `2/3` 这样的位置。 |
| 点击输入框右侧“预测” | 同快捷键，适合关闭自动预测后使用。 |
| 直接打字 | 建议立即消失。把输入框清空后，刚才那条建议会回来。 |

建议不会出现的情况：输入框里已有内容或附件、输入法正在组词、有菜单或对话框打开、助手还在回答、会话为空、窗口不在前台、子代理会话。

模型没有把握时会选择不给建议，这是正常行为。手动触发（按钮或快捷键）会让模型尽量给出一条；确实没有时，输入框里会短暂显示“本次没有建议”和原因。

## 2. 打开设置页

两种方式，内容相同：

- **设置 → 消息预测**。
- 左侧栏的 **消息预测** 入口（需要先添加，见第 4 节）。

页面顶部是标题和版本号（如 `v0.4.0`）。如果下方出现橙色提示“后台仍在运行旧版本”或“后台正在运行 vX，与本页面的 vY 不一致”，说明更新了插件文件但还没有重启 DSH：完全退出并重新打开 DSH 即可。

## 3. 预测模式：一键切换

“预测模式”卡片有三种模式，点一下就切换：

| 模式 | 做了什么 |
|---|---|
| **均衡**（推荐） | 每次回答后自动预测；使用指定的低成本模型；默认上下文（12 条）；每日 200 次。等同于出厂默认。 |
| **省流** | 关闭自动预测，只在你点“预测”或按快捷键时预测；上下文减半（6 条）；每日 60 次。如果“预测”按钮被隐藏了，会重新显示。 |
| **高质量** | 每次回答后自动预测；跟随会话正在使用的模型；发送更多上下文（20 条）；超时放宽到 15 秒。建议更贴合，费用和等待时间更高。 |

需要知道的几点：

- 切换后页面顶部出现“已切换为‘××’模式”和 **撤销** 按钮，10 秒内可以一键恢复到切换前的设置。
- 模式**不会**打开或关闭“启用预测”。预测处于关闭状态时切换模式，提示里会说明“开启后生效”。
- 模式**不会**改动：快捷键、界面语言、常用短句、敏感信息遮蔽、回合统计、读屏播报、左侧栏入口。
- 均衡和省流使用“指定模型”。如果你已经填过模型服务商 ID 和模型 ID，它们会保留；只有两项为空（或是离线测试用的 `fixed-test`）时才填入推荐的 `deepseek-official / deepseek-flash`。
- 切换模式后仍然可以单独调整任何选项。只要有一项与模式不一致，卡片上方就显示“当前为自定义设置”，三个模式都不标“使用中”；这只是说明现状，不影响使用。

三种模式的完整取值见 [CONFIGURATION.md](CONFIGURATION.md#模式取值)。

## 4. 添加到左侧栏

设置页右上角的 **添加到左侧栏** 按钮：

- 点一下，DSH 首页左侧栏的入口列表（“插件”“自动化任务”所在的位置）多出一个 **消息预测** 入口。
- 点击该入口，主区域显示本插件的页面：可以看当前状态和近 7 天统计、切换模式、调整选项，不必打开设置。
- 再点一次按钮（此时显示为 **从左侧栏移除**）即移除入口。在入口打开的页面里移除，页面不会被关掉。
- 这个选择保存在插件配置里，重启 DSH 后仍然有效。

左侧栏收起成窄条时，入口显示为图标，鼠标悬停显示名称。

## 5. 设置页各项

### 基础

| 选项 | 说明 |
|---|---|
| 启用预测 | 总开关，默认关闭。关闭后不显示建议，也不调用模型。下方的“当前状态”说明此刻在做什么，或为什么没有建议。 |
| 回答结束后自动预测 | 关闭后只在手动触发时预测，可减少模型调用。 |
| 显示“预测”按钮 | 输入框为空时在右侧显示按钮。 |
| 预测快捷键 | 点击按钮后按下新的组合键。必须包含 Ctrl、Alt 或 Win；主键不能是 Tab、Esc、回车、退格、删除或方向键；Ctrl 或 Win 加编辑键（复制、粘贴、剪切、撤销、全选、查找、保存等）留给编辑器，不能使用。按 Esc 取消录制。 |
| 界面语言 | 本插件自身文字的语言：本页面、输入框里的按钮和提示。可选 简体中文、English、日本語、한국어、Español、Français、Deutsch、Русский、Português，或“跟随 DSH”（默认，使用 DeepSeek Harness 当前的界面语言）。选中即生效，可撤销。它不改变建议本身的语言，建议沿用对话所用的语言。 |

### 建议来源

| 选项 | 说明 |
|---|---|
| 优先使用常用短句 | 同一会话里你重复发过的短消息（单行，2–20 字，默认至少 2 次）直接作为建议。不调用模型、不计额度、内容不离开本机。 |
| 手动预测返回多条候选 | 手动预测和“换一条”时一次调用返回多条（默认 3 条），之后切换无需等待。自动预测始终只返回一条。 |

### 预测模型

- **指定模型**：填写模型服务商 ID 和模型 ID（与 DSH 模型设置中显示的 ID 一致）。费用和速度不随会话模型变化。该模型不可用时，本次预测临时改用会话模型。
- **跟随会话模型**：会话用什么模型，预测就用什么模型。
- 下拉框选中即生效；三个文本框修改后需要按回车或点“保存”，页面会显示“有未保存的修改”。
- **改用推荐模型**：一键切回 `deepseek-official / deepseek-flash`、关闭推理，可撤销。
- 推理强度只对指定模型严格生效：填 `off` 关闭推理，留空使用该模型的最低档。

### 近 7 天统计

预测请求数、已显示的建议数、已采纳数与采纳率、未给出建议的次数与主要原因、响应时间、token 用量，以及今日额度使用情况。数据来自本机的统计记录，只有次数、耗时和哈希值，不含任何文字。

“今日额度使用”里的 token 数包含为“用量未知的调用”保留的部分（模型已被调用但没有返回用量，例如超时），有这种情况时括号里会注明数量。每日上限就是按这个数字计算的。

### 高级选项

默认折叠。数值项失去焦点或按回车时保存，超出范围会提示并保持原值；数值偏高、会增加费用或发送内容的项会给出橙色说明。“恢复默认值”把高级选项全部恢复为默认。出现配置错误或关闭了敏感信息遮蔽时，这一块会自动展开一次；手动收起后不会再因为保存别的选项而弹开。

“对话 token 上限”是单次预测输入的上限，包含固定的任务说明（约 700 token）和对话片段，最小 1,000。

关闭“发送前遮蔽敏感信息”需要二次确认；关闭期间该项下方一直显示红色提示。

“诊断信息”是插件本次启动以来的原始计数，反馈问题时可以提供。

## 6. 常见问题

**没有建议出现。** 看设置页“当前状态”一行。常见原因：未启用；关闭了自动预测（改用按钮或快捷键）；输入框非空；窗口不在前台；已达到每日上限；模型判断没有合适的建议。

**状态显示“已暂停：检测到其他输入建议插件”。** 同一个 profile 里还启用了另一个幽灵文字插件。两者会争用 Tab 和 Esc，所以本插件主动让位。停用其中一个即可。

**提示“无法调用预测模型，请检查模型设置”。** 指定模型的服务商 ID 或模型 ID 在 DSH 中不存在或未配置。到“预测模型”卡片核对，或点“改用推荐模型”，或改为“跟随会话模型”。

**提示“模型不支持所填写的推理强度”。** 指定模型没有你填的档位。把“推理强度”留空，由插件选择该模型的最低档。

**设置保存失败，并提示后台版本较旧。** 更新了插件文件但 DSH 没有重启。旧后台不认识新选项（例如左侧栏入口）。重启 DSH。

**“已采纳”一直是 0。** 这是 0.2.x 的统计错误，0.3.0 已修复，旧记录升级后也会被正确统计。

**想换界面语言。** “基础”卡片里的“界面语言”，选中即生效。选“跟随 DSH”则随 DeepSeek Harness 的语言变化。

**提示“无法连接插件后台”或“插件后台没有及时响应”。** 页面会保留上一次读到的设置并自动重试，后台恢复后提示自行消失。一直不恢复时，完全退出并重新打开 DSH。

**预测快捷键变回了 Alt+\\。** 以前可以把 Ctrl+V 这类编辑键设为预测快捷键，那会让粘贴失效。0.4.0 起这类组合不再有效，已保存的会退回默认值，并在“诊断信息 → 配置错误”里列出。重新录一个不冲突的组合即可。

**想彻底清除本机数据。** 见 [PRIVACY.md](PRIVACY.md#数据删除)。
