# 隐私与数据边界

适用于 0.6.0。本文说明插件实际处理哪些数据。设置页的说明与本文不一致时，以设置页为准并请反馈。

## 什么时候调用模型

只有同时满足以下条件才会调用：

- “启用预测”已打开（默认关闭）；
- 当前会话未暂停，输入框为空且可编辑，窗口在前台。自动预测等待符合条件的回答结束，手动预测由你点“预测”或在聚焦的输入框按快捷键发起；
- 没有超过每日请求上限和每日 token 上限。

需要发起新的模型预测时，模型请求最多派发一次。使用你在 DSH 中已经配置好的服务商，按当前设置解析指定模型或会话模型。指定模型无法解析时，后台可能改用可用的 DSH 默认模型。在「跟随会话模型」模式下手动预测导入的 DeepSeek 回复时，相关对话片段也会发给 DSH 为该会话选用的服务商。插件复用 DSH 的模型配置。

生成和切换“你自己的短语”无需额外调用模型：

- **常用短句**只在本机比较你在当前会话里发过的短消息，结果排在模型建议之后；
- **固定短语**是你在设置页自己维护的列表，同样只在本机使用；
- 本机候选与固定短语列表不会加到模型提示词的候选列表中。若同样的文字已作为消息发出，仍可能作为最近对话片段发送给模型；
- 手动预测没有得到可用的模型建议时，插件可直接提供已有的本机短语。这一步无需额外模型调用。

## 发送给模型的内容

对话片段由后台从 DSH 的会话存储读取。浏览器的预测与会话状态请求使用会话和回合标识、修订号等元数据。草稿、附件和引用不随这些请求发送。保存固定短语时，页面会把列表写入 DSH 管理的插件配置。

发送的内容是：

- 一段固定的任务说明（提示词）；
- 当前会话分支最近的**用户消息**和**助手的最终文字回答**。不包括工具调用的参数和输出、推理过程、系统提示、技能目录、运行时上下文；
- 默认附带一行上一回合的统计，例如“本回合 12 次工具调用；修改文件 3 次；未观察到测试命令”。只有次数，没有内容。可在“高级选项 → 附带上一回合的统计信息”关闭。

数量上限（默认，可在高级选项或通过模式调整）：最多 12 条消息、约 2,000 token。token 上限包含固定的任务说明（约 700 token）和对话片段两部分。超出时保留最近的内容，被截断处有明确标记；消息再长，片段也不会超过上限。

| 模式 | 消息条数 | token 上限 |
|---|---|---|
| 均衡 | 12 | 2,000 |
| 省流 | 6 | 1,200 |
| 高质量 | 20 | 4,000 |

选择“高质量”或调高上限，会把更多对话内容发给模型；设置页在数值偏高时给出提示。

## 发送前的遮蔽

默认开启。发送前把以下内容替换为占位符：

- 私钥块（`-----BEGIN … PRIVATE KEY-----` 到对应的 END 行）；
- JWT、Bearer 令牌，以及常见平台的密钥和令牌前缀（`sk-`、`sk_live_` / `pk_live_` 等、GitHub、GitLab、Slack、AWS、Google、Hugging Face、npm）；
- 赋值写法：名称里含 api_key、secret、password、token、cookie 或“密码”“口令”“密钥”“令牌”的项，后面用 `=`、`:`、全角冒号或“是”“为”给出的值（如 `password=…`、`密码：…`）；
- 邮箱地址，包括 `name [at] example.com` 这样的写法；
- 中国大陆手机号和 18 位身份证号；
- 个人文件夹路径中的用户名（Windows 的 `Users` 目录和 Unix 的 `home` 目录下的第一级名称），路径的其余部分保留；
- 看起来像密钥的长随机串。

提交号、UUID、普通的长名称和用量数字不会被改动。

这是基于规则的匹配，**不能保证识别所有敏感信息**。可以在高级选项中关闭（需要二次确认）；关闭后对话片段原样发送，设置页持续显示红色提示。

## 本机保存的数据

都在 `<DSH_HOME>/next-message-predictor/`（默认 `~/.dsh/next-message-predictor/`）：

| 文件 | 内容 | 保留时间 |
|---|---|---|
| `ledger.json` | 每次模型调用的时间、会话与回合标识、服务商、模型、是否已显示、进行中时预留的 token 数；每个回答已调用模型的次数（自动、手动，按会话与回合标识记）；按日汇总的请求数和 token（实测、估算、进行中的预留分开记） | 调用记录与回答次数 24 小时（次数最多 2,000 条），日汇总 7 天 |
| `events.jsonl` | 每次预测请求一行：时间、标识的哈希值、触发方式、结果与原因、耗时、token、建议的字数；建议是否显示、被采纳或隐藏；你下一条消息与建议的相似度分数 | 5 MB 轮换，旧文件 14 天后删除 |

0.5.0 起 `events.jsonl` 多记几个字段，全是数字或标记，不含文字：请求行有 `nm`、`nh`、`np`（这一次的环里有几条模型候选、常用短句、固定短语）、`fb`（这是手动预测的本机回退）、`cached`（结果来自缓存）；“采纳”行有 `source`（`model` / `habit` / `pinned`）和 `index`（环里的第几条）；“匹配”行有 `nomodel`（这条建议里没有模型候选可比）和 `local`（你的下一条消息和哪一类自己的短语一致）。仍然没有对话文字，也没有建议或短语的文字。

两个文件都**不保存建议的文字和对话的文字**。`events.jsonl` 里的会话、回合、建议标识是加盐哈希。

建议的文字只在后台内存里短暂保留（最多 2 小时、200 条），用来在你发出下一条消息时计算相似度分数；算完即丢弃，进程结束也随之消失。

另外：

- 插件配置保存在 DSH profile 的配置文件中，由 DSH 管理。**固定短语**作为配置项 `pinnedPhrases` 明文保存，其列表不会写入 `ledger.json`、`events.jsonl` 或模型提示词。
- 浏览器的 `localStorage` 保存一个标记（是否添加了左侧栏入口），`sessionStorage` 保存“高级选项”是否展开。不含任何对话内容。
- 诊断计数只在后台内存中，进程结束即消失。后台日志只有原因码、耗时、模型标识和用量。
- 会话暂停和跨窗口同步状态只存在当前 DSH 后台内存中。状态查询和变更使用会话、回合标识与修订号，不传输草稿、建议或对话文字。

## 不做的事

- 不发送消息。采纳建议只是把文字填进输入框；插件代码里没有提交或发送的调用。
- 不向模型服务商以外的任何地方上传数据，不做遥测。
- 不保存会话副本。

DSH 本身可能有自己的遥测，本插件无法改变也不参与。

## 数据删除

| 想清除 | 做法 |
|---|---|
| 统计记录 | 删除 `<DSH_HOME>/next-message-predictor/events*.jsonl` |
| 调用记录与每日用量 | 删除 `<DSH_HOME>/next-message-predictor/ledger.json`（当日已用额度和每个回答的手动预测次数随之清零） |
| 全部本机数据 | 删除 `<DSH_HOME>/next-message-predictor/` 整个目录 |
| 插件配置 | 在设置页恢复默认，或删除 profile 的 `cordis.patch.yml` 中 `next-message-predictor` 条目的 `config` |
| 固定短语 | 在设置页“建议来源 → 固定短语”里逐条“删除”，再点一次“保存”；“恢复默认值”不会清除它们。也可以直接删掉配置里的 `pinnedPhrases` 一项 |
| 插件本身 | `dsh plugin --profile <profile> remove dsh-next-message-predictor`，然后重启 DSH。卸载会移除路由、监听器和界面入口 |

删除文件前请先退出 DSH，否则运行中的后台可能把内存中的状态重新写回。

## 评测数据

仓库中的 `eval/fixtures.deidentified.jsonl` 是纯合成样本，不来自真实对话。`eval/replay-*.json` 是在本机用真实会话回放得到的指标，只包含哈希标识、长度和分数，不含对话文字。
