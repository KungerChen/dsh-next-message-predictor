# 隐私与数据边界

适用版本：0.3.0。本文说明插件实际处理哪些数据。设置页的说明与本文不一致时，以设置页为准并请反馈。

## 什么时候调用模型

只有同时满足以下条件才会调用：

- “启用预测”已打开（默认关闭）；
- 一次回答正常结束，且输入框为空、可编辑、窗口在前台；或者你主动点了“预测”/按了快捷键；
- 没有超过每日请求上限和每日 token 上限。

每次预测调用模型一次，不自动重试。调用的是你在 DSH 中已经配置好的模型服务商（指定模型，或会话正在使用的模型）。插件不新增密钥输入框，不接入新的第三方服务。

“常用短句”不调用模型：它只在本机比较你在当前会话里发过的短消息。

## 发送给模型的内容

内容由后台直接从 DSH 的会话存储读取。浏览器页面只发送会话与回合的标识、配置版本和触发方式，**不发送草稿、附件、引用或任何对话文字**。

发送的内容是：

- 一段固定的任务说明（提示词）；
- 当前会话分支最近的**用户消息**和**助手的最终文字回答**。不包括工具调用的参数和输出、推理过程、系统提示、技能目录、运行时上下文；
- 默认附带一行上一回合的统计，例如“本回合 12 次工具调用；修改文件 3 次；未观察到测试命令”。只有次数，没有内容。可在“高级选项 → 附带上一回合的统计信息”关闭。

数量上限（默认，可在高级选项或通过模式调整）：最多 12 条消息、约 2,000 token。超出时保留最近的内容，被截断处有明确标记。

| 模式 | 消息条数 | token 上限 |
|---|---|---|
| 均衡 | 12 | 2,000 |
| 省流 | 6 | 1,000 |
| 高质量 | 20 | 4,000 |

选择“高质量”或调高上限，会把更多对话内容发给模型；设置页在数值偏高时给出提示。

## 发送前的遮蔽

默认开启。发送前把以下内容替换为占位符：`sk-…` 形式的密钥、Bearer 令牌、JWT、常见平台令牌前缀（GitHub、Slack、AWS）、`api_key=` / `password=` / `token=` 这类赋值、邮箱地址，以及看起来像密钥的长随机串。

这是基于规则的匹配，**不能保证识别所有敏感信息**。可以在高级选项中关闭（需要二次确认）；关闭后对话片段原样发送，设置页持续显示红色提示。

## 本机保存的数据

都在 `<DSH_HOME>/next-message-predictor/`（默认 `~/.dsh/next-message-predictor/`）：

| 文件 | 内容 | 保留时间 |
|---|---|---|
| `ledger.json` | 每次模型调用的时间、会话与回合标识、服务商、模型、是否已显示；按日汇总的请求数和 token | 调用记录 24 小时，日汇总 7 天 |
| `events.jsonl` | 每次预测请求一行：时间、标识的哈希值、触发方式、结果与原因、耗时、token、建议的字数；建议是否显示、被采纳或隐藏；你下一条消息与建议的相似度分数 | 5 MB 轮换，旧文件 14 天后删除 |

两个文件都**不保存建议的文字和对话的文字**。`events.jsonl` 里的会话、回合、建议标识是加盐哈希。

建议的文字只在后台内存里短暂保留（最多 2 小时、200 条），用来在你发出下一条消息时计算相似度分数；算完即丢弃，进程结束也随之消失。

另外：

- 插件配置保存在 DSH profile 的配置文件中，由 DSH 管理。
- 浏览器的 `localStorage` 保存一个标记（是否添加了左侧栏入口），`sessionStorage` 保存“高级选项”是否展开。不含任何对话内容。
- 诊断计数只在后台内存中，进程结束即消失。后台日志只有原因码、耗时、模型标识和用量。

## 不做的事

- 不发送消息。采纳建议只是把文字填进输入框；插件代码里没有提交或发送的调用。
- 不向模型服务商以外的任何地方上传数据，不做遥测。
- 不保存会话副本。

DSH 本身可能有自己的遥测，本插件无法改变也不参与。

## 数据删除

| 想清除 | 做法 |
|---|---|
| 统计记录 | 删除 `<DSH_HOME>/next-message-predictor/events*.jsonl` |
| 调用记录与每日用量 | 删除 `<DSH_HOME>/next-message-predictor/ledger.json`（当日已用额度随之清零） |
| 全部本机数据 | 删除 `<DSH_HOME>/next-message-predictor/` 整个目录 |
| 插件配置 | 在设置页恢复默认，或删除 profile 的 `cordis.patch.yml` 中 `next-message-predictor` 条目的 `config` |
| 插件本身 | `dsh plugin --profile <profile> remove dsh-next-message-predictor`，然后重启 DSH。卸载会移除路由、监听器和界面入口 |

删除文件前请先退出 DSH，否则运行中的后台可能把内存中的状态重新写回。

## 评测数据

仓库中的 `eval/fixtures.deidentified.jsonl` 是纯合成样本，不来自真实对话。`eval/replay-*.json` 是在本机用真实会话回放得到的指标，只包含哈希标识、长度和分数，不含对话文字。
