- `src/host/build-integrity.js` 定义运行时输入和构建器字节的指纹，核验当前 profile 安装路径及生成文件。`scripts/build-client.mjs` 生成 `src/shared/build-id.js`、`lib/client.js` 和 `lib/build-manifest.json`，分发清单与 CI 检查已纳入相关文件。

- 架构、配置、兼容、隐私、开发、分发、使用指南和九语言 README 已同步当前实现。生成检查与 `git diff --check` 通过；真实产品隔离和原生验收仍待核验。
